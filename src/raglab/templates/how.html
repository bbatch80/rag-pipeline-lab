How it works

Flow 1An unstructured source goes in

  1. Fetchreal PDFs from OPM; synthetic records generated
  2. Parselayout model reads titles, text, tables, pages
  3. Chunkby heading; tables kept whole
  4. Gatea bad parse is quarantined, never indexed
  5. De-identifyPHI pseudonymized before anything is stored
  6. Embed & indexvectors, keywords, metadata on every chunk

Flow 2A question comes in

  1. Identityrole resolved at the edge, never from the question
  2. Contextmember, claim, case ids become filters
  3. Routeyears, plans, options, as-of date
  4. Planthe model proposes legs; the code governs them
  5. Searchvector + keyword, under row-level security
  6. Reranka judge scores every candidate; abstains below the bar
  7. Warehousenamed Snowflake queries as your role
  8. Payloadone versioned contract: status, evidence, provenance
  9. Discloselogged before it is delivered, or not delivered

Flow 3Proving it works

  1. Golden set163 questions with the evidence each must return
  2. The gateevery pull request ratchets against the baseline
  3. Per rolerecall measured under each role's entitlements
  4. Dashboardthe scorecard every full run rewrites
